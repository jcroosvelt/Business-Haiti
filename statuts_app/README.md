# Statuts — planificateur privé de statuts WhatsApp (Flutter)

- Médias copiés dans le stockage privé de l'appli, code d'accès local.
- Jusqu'à 50 fichiers par statut, partagés d'un coup via le menu de partage Android.
- L'APK est compilé par GitHub Actions (`.github/workflows/build-apk.yml`) : onglet **Actions** → dernier run → artefact `statuts-apk`, ou onglet **Releases**.
